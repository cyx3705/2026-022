## 0. 一句话定义

**v2.9** 把右侧战斗从「弹丸直击炮塔扣血」改为**领地战**：战场铺满领地网格，四象限开局各归其主；投射球不再直接伤害炮塔，而是**沿途啃食敌方格子、推进己方领地**；敌方领地一路推到你的**本垒格**，炮台才陷落。同时**整顿画面**：顶部 HUD 压缩、删除无意义的"RUN-大球-小球"武器条；**左侧落球减速**。

节奏问题的根治：此前一局 ~10 秒是因为弹丸无消耗直达炮塔。产品拍板**不做弹-弹抵消**，改用领地机制——弹丸有限的"占领预算"耗尽即消失，战线必须一格格推进，对局自然拉长为拉锯战。

## 1. 功能需求

### 1.1 领地战（P0，默认模式 `mode=territory`）

| 编号 | 需求 |
|---|---|
| TE-01 | 战场铺**领地网格**（格尺寸 `cellSize` 可配，默认 20px；960×900 → 48×45 格）；开局按象限均分归属，无主象限为中立 |
| TE-02 | 投射球带**占领预算**（随伤害/球大小增长：`⌈√damage/250⌉`）；进入非己方格即**夺格**（染为己色），预算 -1；预算耗尽球消失 |
| TE-03 | **护盾护本垒**：夺取的格子若在该格主人炮台护盾半径内且其 Shield>0，则本次夺格被护盾挡下（Shield -20 万/格，预算照扣）；护盾破后本垒圈才可被蚕食 |
| TE-04 | **陷落规则**：炮台**本垒格**（炮台中心所在格）被夺 → 炮台死亡（沿用 Kill：清弹、左侧断粮、清分）；存活 ≤1 判胜负（复用现有导演） |
| TE-05 | HP 语义切换：领地模式下 `Hp=当前拥有格数`、`MaxHp=开局格数`，HUD/卡片血条即领地占比；直击旧语义保留于 `mode=direct` |
| TE-06 | 大球/小球经济语义自然迁移：大球积分→单弹啃更多格；小球积分→多弹多路推进;护盾积分→本垒圈耐久 |
| TE-07 | 领地入确定性哈希（同种子同战线）；`arena.mode territory|direct` 指令切换 |

## 2. 验收标准

1. `demo.play seed=42`：战场四色领地开局均分，战线随弹幕逐格推进，弹丸啃完预算即消失，不再有"开局十秒团灭"。
2. 60 秒无头验证：无人死亡（或至少战局未结束）、夺格数 > 0、同种子领地哈希一致。
3. 敌方战线推进至本垒格且护盾耗尽 → 炮台陷落 → 其左侧停止吐球；存活 ≤1 出胜者。
4. HUD 顶带 ≤50px、无武器条；左侧落球肉眼可见变慢。
5. 构建零警告；`mode=direct` 回退旧玩法可用；版本 **2.9.0**。
