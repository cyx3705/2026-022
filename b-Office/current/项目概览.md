# WBall 项目概览

更新日期：2026-08-01  
当前版本：3.6.0

## 一句话定义

WBall 是一个基于 .NET 8、WPF 与 OneHistory AppShell 的可配置落球对战模拟器，将落球经济、炮台战斗、场景编辑和离线出片组合为可确定复现的桌面应用。

## 目标与边界

### 目标

- 以固定时间步和种子复现提供可调、可验证的落球对战模拟。
- 在 2 万总球数下保持可验收的实时帧率、交互响应和稳态内存，同时保持离线出片独立性。
- 通过统一命令总线和场景调试窗口提供一致的编辑与调试入口。
- 保持日常规则修改可在 Core/Application 层快速验证。

### 范围

- 落球经济、阵营积分、弹药、护盾、炮台、领地和胜负结算。
- 对战平衡、友军积分传递与吸收、升格弹回收和确定性降速。
- 场景、球、公式、阵营、炮台、武器和出片配置。
- 实时预览与独立世界中的 winner-only H.264 MP4 离线帧组合。

### 非目标

- 不修改或复制 AppShell 源码，不在 WBall 内维护框架分叉。
- 不提供网络对战、云端服务或默认开启的 WBall MCP。
- 不为了整理文档而迁移用户场景、布局、配置或录制输出格式。
- 不全面重写玩法；V3.7 允许为线程所有权、空间索引和低分配热路径拆分 `BattleRuntime` 相关热点。

## 关键约束

- 平台：Windows、.NET 8、WPF。
- 框架：只消费 `OneHistory.AppShell.Shell 3.0.3` 正式包。
- 兼容性：v3.1/v3.2 回退哈希冻结；场景文件和用户数据位置不隐式迁移；V3.6 只改变新任务的出片接口和输出格式，不清理已有录制结果。
- 写入路径：场景调试 UI 和控制台通过同一 CommandBus 与 Application 用例修改权威状态。
- MCP：WBall 默认显式关闭；OHS 的项目管理 MCP 属于独立宿主，不改变该设置。
- 资源：球数过高时使用确定性模拟降速；V3.7 只能降低实时视觉细节，不得减少或聚合模拟实体。离线出片使用独立世界，不依赖实时模拟线程，也不设置生成速度门限。
