## 0. 一句话定义

**v1.5.2** 在 v1.5.1 之上补齐四件事：

1. **异形实体默认颜色与手动方块一致**；  
2. **场景相关操作从落球工具中拆出**，独立成「场景」控制窗口；  
3. **小球销毁→重生改为传送**（同 id 到生成器），并加 **尾迹** 使传送可见；顺带缓解「球一多就卡」；  
4. 新增 **对象调试窗口**：与表窗口/投影表编辑语义一致，但颜色用更易用的选择器（预览 + 基础色，类似 PPT）。

## 1. 背景与痛点

| 痛点 | 说明 |
|---|---|
| 异形与方块色不一致 | 异形偏蓝、方块偏灰石色，并置不统一 |
| 落球面板过重 | `dropzone` 混杂放置工具、仿真、场景尺寸/存取；场景管理应独立窗口 |
| 销毁/创建卡顿 | 当前销毁器路径易走「移除再生成」或频繁分配；球多时 GC/列表抖动明显 |
| 传送不可见 | 若改为瞬移到生成器，无视觉线索会像「瞬移 bug」 |
| 调参入口分散 | 表窗口能改投影，但缺面向「当前选中对象」的调试壳；颜色改 `#hex` 不友好 |

## 2. 目标与非目标

### 2.1 目标

| 编号 | 目标 |
|---|---|
| G1 | 异形实体（solid/mesh）**默认填充色 = 方块 block 同色**（见 §4.1） |
| G2 | **场景窗**独立：尺寸、存取、scenes 刷新等迁出落球窗 |
| G3 | 销毁器命中后默认 **传送到随机生成器**（保留 id / 属性补丁规则），**不**先销毁再新建实例 |
| G4 | 小球具备 **尾迹**；传送瞬间尾迹可辨认「从销毁点飞到生成点」的语义（或残留残影） |
| G5 | 球多时帧时间可接受：减少分配、避免每帧全表重建；给出可测指标（§10） |
| G6 | **对象调试窗**：编辑当前选中对象/球，与 `scene_objects` / `balls` / solids 投影字段一致；颜色选择器带预览与基础色板 |
| G7 | 一切仍走指令总线；运行时权威仍在 SceneWorld；不改冻结区 |

### 2.2 非目标

- 不做视频录制/导出。  
- 不做完整粒子系统/流体尾迹（尾迹为轻量轨迹点列即可）。  
- 不把表窗口替换掉（调试窗是增强，不是废除 `db.*` / 表窗）。  
- 不引入第三方物理库。  
- 不在本版做网络联机。  
- 颜色选择器不做完整专业取色器（HSV 三维、色轮插件等）——「够用像 PPT」即可。

## 3. 与既有版本关系

```
v1.5.0  线框草图 / close / solidify（曾错误多 block）
v1.5.1  单异形 + 三角碰撞 + 无边框
        │
        ▼
v1.5.2  异形配色对齐 / 场景窗拆分 / 传送+尾迹+性能 / 对象调试窗
```

| 既有能力 | v1.5.2 如何用 |
|---|---|
| block 填充色（如 `#64748B`） | 异形默认同色 |
| `dropzone.json` 面板 | 拆分：保留放置+仿真；场景项迁到 `scene.json`（或等价 id） |
| 销毁器补丁 / 随机生成器重生 | 改为 **同实例传送**，补丁仍可应用 |
| `balls` / `scene_objects` 投影 | 调试窗读写映射到同一套字段与指令 |
| 指令单点语法 | 新增/调整命令仍遵守 `域.动作` |

## 4. 功能需求

### 4.1 异形实体颜色对齐方块（P0）

| 编号 | 需求 | 优先级 |
|---|---|---|
| CL-01 | 异形实体默认填充色与手动 **block** 默认色一致（当前实现参考：石板灰 `RGB(0x64,0x74,0x8B)` / `#64748B`） | P0 |
| CL-02 | 无边框规则不变（v1.5.1）；仅改填充色值 | P0 |
| CL-03 | 若异形后续支持自定义颜色，默认值仍等于 block 默认；自定义走调试窗/投影 | P1 |
| CL-04 | 线框预览色可继续用区分色（蓝系），以免未实体化与已实体化混淆；**实体化完成后**必须是方块同色 | P0 |

### 4.2 场景模块拆分为独立窗口（P0）

> 用户定调：拆分落球模块，**场景相关内容独立为一个窗口**。

| 编号 | 需求 | 优先级 |
|---|---|---|
| SC-01 | 新增控制面板（建议 id=`scene`，标题「场景」），与 `dropzone` / `wireframe` 并列写入 `panels/` | P0 |
| SC-02 | **迁入场景窗**的控件（至少）：场景宽/高、应用尺寸、查询尺寸、场景名、保存/加载/核对、当前场景、场景列表、刷新场景表、新建场景 | P0 |
| SC-03 | **留在落球窗**的控件：选择/方块/箭头/生成器/销毁器、播放/暂停/重置、重力、球碰开关、吐球、打开线框窗、状态 | P0 |
| SC-04 | 落球窗可保留一个「打开场景窗」按钮（`panel.show id=scene`） | P1 |
| SC-05 | 场景窗默认停靠右侧（可 Tab）；布局可持久化 | P0 |
| SC-06 | 不改 DockingHost / 面板 JSON 字段契约；只用既有控件类型 | P0 |
| SC-07 | 指令不变（仍 `scene.size` / `scene.save` …）；只是触发入口搬家 | P0 |

**拆分后职责一览**

| 窗口 | 职责 |
|---|---|
| 落球工具 `dropzone` | 编辑工具 + 仿真控制 |
| 线框工具 `wireframe` | 草图 / 闭合 / 实体化 |
| **场景 `scene`（新）** | 世界尺寸 + 场景文件管理 |
| 对象调试 `objdebug`（新，§4.5） | 选中对象/球属性调试 |

### 4.3 小球：传送代替销毁重建 + 性能（P0）

#### 4.3.1 传送语义（产品定稿倾向）

| 编号 | 需求 | 优先级 |
|---|---|---|
| TP-01 | 小球进入销毁器后：**不**从列表 Remove 再 `new Ball`；对 **同一 Ball 实例** 执行传送 | P0 |
| TP-02 | 传送目标：随机一个生成器中心（无生成器则：可真正移除并告警——与 v1.3 一致） | P0 |
| TP-03 | 传送时：应用销毁器 patch → 再应用生成器 patch（顺序与现规范一致）；`id` 不变 | P0 |
| TP-04 | 传送时：位置设为生成器中心；速度清零（或可配置保留——默认清零） | P0 |
| TP-05 | 禁止为「看起来像重生」而分配新 id | P0 |

```
命中 Despawner
  → ApplyPatch(despawner)
  → 选随机 Spawner
  → ApplyPatch(spawner)
  → 写 X/Y 到 spawner 中心，Vx=Vy=0
  → 标记传送事件（供尾迹，§4.4）
  → 不 Remove / 不 new
```

#### 4.3.2 性能优化（与传送配套）

| 编号 | 需求 | 优先级 |
|---|---|---|
| PF-01 | 热路径避免每球每帧装箱、字符串拼接、反复 `List` 扩容 | P0 |
| PF-02 | 投影表防抖已有则保留；仿真高频 `NotifyChanged` 不得导致每帧全表 DELETE+INSERT（可降频或仿真中暂停刷表） | P0 |
| PF-03 | 碰撞宽相位可做粗测（如网格/仅近邻）；P1 若时间不够可先做传送+减分配 | P1 |
| PF-04 | 尾迹点列有上限（环形缓冲），禁止无限增长 | P0 |
| PF-05 | 验收：同场景下球数提高到约定阈值（如 50 / 100）时，编辑机可维持可玩帧率（见 §10） | P0 |

> 说明：传送是 **语义正确 + 减分配** 的主手段；额外空间哈希等为增强。

### 4.4 小球尾迹（P0）

目的：让玩家/作者看见「传送」而不是凭空消失/出现。

| 编号 | 需求 | 优先级 |
|---|---|---|
| TR-01 | 每个球维护短轨迹点列（世界坐标）；仿真步进时追加当前位置 | P0 |
| TR-02 | 绘制：球后方半透明渐隐折线/点列；颜色取自球色或略淡 | P0 |
| TR-03 | **传送时**：保留传送前尾迹一段，并可选画一条「传送残影线」（销毁点→生成点，短时淡出）以便识别瞬移 | P0 |
| TR-04 | 面板或指令可开关尾迹：`sim.trail on=true|false`（默认开） | P1 |
| TR-05 | 轨迹长度 / 残影时长可配置（数字框或常量）；有上限 | P0 |
| TR-06 | 编辑态（暂停）可不更新尾迹；播放态更新 | P0 |

### 4.5 对象调试窗口（P0）

> 用户定调：新建对象调试窗口；**调试与改数据库表一致**；颜色选择器要更好（预览 + 基础色，类似 PPT）。

| 编号 | 需求 | 优先级 |
|---|---|---|
| DB-01 | 新增面板或 App 自研工具窗（建议面板 id=`objdebug`，标题「对象调试」；若标准面板控件不够承载颜色预览，允许 **App 自由区自绘 UserControl** 作为 Main 旁工具内容——**优先**能用面板+指令完成的字段用面板，颜色器用自绘控件嵌入或独立 ToolWindow） | P0 |
| DB-02 | 调试对象范围：当前选中的 **block / solid / arrow / spawner / despawner / ball** | P0 |
| DB-03 | 字段与投影表一致：改调试窗 = 改 SceneWorld = 刷投影表；禁止只改 UI 内存或只改库 | P0 |
| DB-04 | 提交方式：控件变更经指令（如 `scene.set` / `ball.set` / `solid.set`）回显到控制台 | P0 |
| DB-05 | 无选中时显示占位提示「请在落球区选中对象或球」 | P0 |
| DB-06 | 与表窗口并行：表改一行 ↔ 调试窗反映同一权威（以 SceneWorld 为准） | P0 |

#### 4.5.1 建议可调字段（与表对齐）

| 对象 | 字段（示例） |
|---|---|
| block / solid | id(只读)、x、y、w/h（block）、rotation、**color**（若有） |
| arrow | x、y、w、h、rotation/dir、radius、strength |
| spawner / despawner | x、y、w、h、patch |
| ball | id(只读)、color、weight、size、自定义 props；**无 x/y 列**（位置不入库纪律不变） |

> 球位置仍只在内存；调试窗若显示 x/y 仅只读 HUD，或明确标注「不写库」。

#### 4.5.2 颜色选择器（PPT 风）

| 编号 | 需求 | 优先级 |
|---|---|---|
| CP-01 | 提供 **颜色预览块**（当前色实时显示） | P0 |
| CP-02 | 提供 **基础色板**（约 8～16 色，含方块默认灰、常见球色等）；点击即选中并预览 | P0 |
| CP-03 | 支持自定义：HEX 输入（`#RRGGBB`）或系统取色（可选）；改完预览同步 | P0 |
| CP-04 | 「应用」或失焦提交 → 发 `ball.set color=` / `scene.set` / `solid.set color=` | P0 |
| CP-05 | 预览演示：切换色板时预览块立即变，**未点应用前**可不写 SceneWorld（或即时写——二选一，建议 **即时写便于所见即所得**，与表编辑一致） | P0 |
| CP-06 | 不做完整 PPT 主题系统；只要「预览 + 基础色 + HEX」 | P0 |

**实现边界提示**

- 标准 `panels/*.json` 可能无色板控件 → **对象调试窗允许 App 自由区自绘**，经 `ShellConfig` 注册为工具窗口内容，或面板内嵌自定义控件（若模板支持）。  
- 若必须改冻结区才能嵌自定义控件 → **上报**，备选：调试窗纯自绘 ToolWindow + 指令。

## 10. 验收标准（v1.5.2）

1. 新实体化异形填充色与默认方块目视同色。  
2. 存在独立「场景」窗；场景尺寸/存取按钮不在落球窗主路径（或仅留入口跳转）。  
3. 球进销毁器后 id 不变、出现在某生成器处；控制台/日志无「新建 ballN」风暴。  
4. 播放时球有尾迹；传送时能看出从销毁区到生成区的过程或残影。  
5. 同机对比：球数量较多时卡顿相对 v1.5.1 销毁重建路径有改善（可录帧时间或主观可玩）。  
6. 对象调试窗能改选中对象/球颜色；预览块与色板可用；改完表窗口同行颜色一致。  
7. 球位置仍不进 `balls` 表。  
8. 无第三方物理库；未改冻结区（或已上报）。  
9. 版本号 **1.5.2**。

## 11. 风险

| 风险 | 应对 |
|---|---|
| 面板无法做色板 | App 自绘调试窗；不上报则不碰 Shell |
| 尾迹过重 | 环缓上限、降采样、可关 |
| 传送太快看不清 | 残影线 200–400ms 淡出 |
| 拆面板用户找不到存档 | 落球窗留「打开场景窗」；文档/HUD 提示 |
| 投影刷新仍卡 | 仿真中降频 SyncFromWorld |
