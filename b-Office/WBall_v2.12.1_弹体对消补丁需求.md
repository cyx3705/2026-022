# WBall · v2.12.1 补丁需求 —— 弹体不灭与敌弹对消

> 文档性质：补丁需求（基线 v2.12）。 日期：2026-07-26 ｜ 版本：**2.12.1**

## 需求

| 编号 | 需求 |
|---|---|
| BD-01 | **弹丸不再超时消失**：删除 `ProjectileLifetimeSec` 寿命回收；弹只因「啃完预算 / 撞护罩被抵消 / 与敌弹对消」而消失（MaxProjectiles 上限兜底仍在） |
| BD-02 | **敌对弹对消**：异色弹相撞（物理碰撞已有动量反弹）时价值互抵 `cancel = min(v1, v2)`，双方同扣；扣至 0 的弹湮灭 |
| BD-03 | 推论语义：小球(1)撞大球 → 小球消失、大球数值 -1；大球对撞 → 按较小方数值比例抵消（与撞护罩同式）；小球对撞 → 双双湮灭 |
| BD-04 | 同色弹只物理碰撞不抵消;对消判定用空间分桶,防弹幕峰值 O(n²);全程确定性 |

## 验收

1. 观察不到弹丸"无故消失"；场上弹只在啃格耗尽、撞护罩、对消三种情形消失。
2. 小球流撞向敌方大球可见大球数值被逐发磨小；两颗大球对撞后小的消失、大的减值并弹开。
3. 60 秒无头验证通过（同种子哈希一致）；构建零警告。
