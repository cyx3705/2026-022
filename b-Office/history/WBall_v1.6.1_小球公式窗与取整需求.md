## 0. 一句话定义

**v1.6.1** 纠正 v1.6.0 中「标号→重量/尺寸」的配置与计算路径：

1. **废除表窗口公共行**及一切「在数据库/投影表里换算公式」的做法；  
2. 新增 **小球对象窗口**：下方为 **size/重量公式区**，在此配置如何由标号换算尺寸与重量，并设置新建球的**初始值**；  
3. 公式算出 size/weight 后 **立即取整**，禁止长期保留高精小数导致物理/绘制性能恶化。

玩法（`Xn` / `RUN` / 裁判）不变，只改「公式从哪改、存在哪、怎么算」。

---

## 1. 问题陈述（v1.6.0 为何要改）

| 现象 | 根因（产品层） |
|---|---|
| size/重量「倍率」难调、入口别扭 | 公式参数塞在表头 `__public__` + `formula` 面板，与「改球」心智分裂 |
| 性能很差 | 倍率变化后 size/weight 保持浮点细量；碰撞与积分路径负担大 |
| 表与公式耦合 | 在投影/Query 层合成公共行、改表即改公式，**错误地把换算权威放进数据库视图** |

**定调**：换算权威只在 **运行时公式配置（小球对象窗）**；库表只镜像球的**已取整结果**（及倍率整数），**不做换算引擎**。

---

## 2. 目标与非目标

### 2.1 目标

| 编号 | 目标 |
|---|---|
| G1 | **删除公共行**：`balls`（及其它表）Query 不再前置 `__public__`；相关 UI/文案移除 |
| G2 | 新增 **小球对象窗口**（可与现有「对象调试」合并升级，或独立 `ballpanel` ToolWindow——见 §9） |
| G3 | 窗口**下方**固定 **公式区**：配置标号→`size`、标号→`weight` 的换算；可设初始标号等默认 |
| G4 | 公式变更或球倍率变更后：在内存中重算 size/weight，**立即取整**再写入球与投影 |
| G5 | **禁止**通过改 `balls` 表公共行或 SQL 驱动公式；表只显示/可改结果列（倍率变化仍可覆盖 size/weight，沿用 V6Q11 语义） |
| G6 | 性能：球多时帧时间相对 1.6.0 有体感改善（取整 + 去掉公共行合成开销） |
| G7 | 版本号 **1.6.1**；不改冻结区 |

### 2.2 非目标

- 不改 `Xn` / `RUN` / 裁判玩法语义  
- 不做任意脚本公式语言（仍为参数化公式：base + scale×f(标号)）  
- 不恢复 Excel 单元格寻址公共行  
- 不把公式参数写入场景 JSON（默认仍全局配置文件；场景级公式为 P2）

## 4. 术语

| 术语 | 含义 |
|---|---|
| **标号 / 倍率** | 球心整数标号（仍可用 K/M/G/T 显示） |
| **公式区** | 小球对象窗下半区：标号→尺寸、标号→重量的参数与预览 |
| **初始值** | 新建球默认：初始标号、以及公式用到的 base/scale 等（在公式区设置） |
| **取整** | 公式输出后对 size、weight 做整数化（见 §5.3），再参与物理与入库 |

### 5.3 公式与取整（性能关键）

**默认公式形态（可与 1.6.0 一致，仅强制取整）：**

```
sizeRaw   = SizeBase + SizeScale × √(max(1, multiplier))
weightRaw = WeightBase + WeightScale × √(max(1, multiplier))
size      = Round(sizeRaw)     // 见取整规则
weight    = Round(weightRaw)   // 或对 weight 用更粗粒度
```

| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-01 | 每次由标号推导 size/weight 时，**先算后取整，再赋给 Ball**；禁止把未取整的 double 长期留在热路径 | P0 |
| FR-02 | **size 取整规则（建议）**：`Math.Max(2, (int)Math.Round(sizeRaw))`，上限如 72 | P0 |
| FR-03 | **weight 取整规则（建议）**：`Math.Max(1, (int)Math.Round(weightRaw))`（重量用整数单位，避免 0.01 级浮点） | P0 |
| FR-04 | 投影表 `size`/`weight` 列写入**已取整值**；SQLite 可用 INTEGER/REAL 存整数 | P0 |
| FR-05 | 物理引擎使用已取整的 Size/Weight，不再在碰撞内做公式 | P0 |
| FR-06 | 标号仍为整数；显示 K/M/G/T 不变 | P0 |

> 用户原话对应：**完全放弃在数据库中做从标号换算到重量尺寸**；换算只发生在内存公式函数里，且马上取整。

## 9. 验收标准（v1.6.1）

1. `balls` 表首行不再出现 `__public__`。  
2. 小球对象窗下区可改 SizeBase/Scale、WeightBase/Scale、初始标号并保存。  
3. 球进 `X5` 后 size/weight 为整数，且随标号变化。  
4. 不再依赖表编辑来改公式参数。  
5. 同场景多球时，相对 1.6.0 卡顿有改善（主观可玩或简易帧时对比）。  
6. `Xn` / `RUN` / 裁判 / 开局回归通过。  
7. 版本号 **1.6.1**。

## 10. 风险

| 风险 | 应对 |
|---|---|
| 取整过粗导致球几乎一样大 | 调默认 Scale；预览区即时反馈 |
| 用户仍找旧 formula 面板 | 删除或改为打开小球窗 |
| 旧档浮点 size | 加载时 Round 一次 |
