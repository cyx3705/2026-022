## 0. 一句话定义

**WBall** 是基于 AppShell 派生的**小球对战 / 落球仿真游戏**（远期可做成视频生成器）：在可编辑的「落球区」中布置方块、重力箭头、小球生成器与销毁器，驱动小球物理运动与属性流转。

**v1.3 唯一交付焦点**：把**落球区**做完整——可编辑、可仿真、可表驱动属性、可指令完备。  
**视频录制 / 导出 / 预览窗**属很后期内容，本版及近期版本均不出现相关功能与占位。

## 1. 背景与目标

### 1.1 产品背景

市面上常见「彩色小球坠落 / 碰撞 / 消除 / 再生成」内容，本质是：

1. 一块二维落球舞台（障碍物 + 重力场 + 出入口）；
2. 一群带属性的小球在舞台上运动；
3. 生成器 / 销毁器形成闭环循环；
4. （很后期）才可能把过程录成视频——**不在 v1.3 范围**。

WBall v1.3 先做成**可玩可改的落球仿真游戏**，只做第 1～3 步的「落球区」闭环。

### 1.2 v1.3 目标

| 编号 | 目标 |
|---|---|
| G1 | **落球区可手改**：在左窗落球区手动放置 / 选择 / 移动 / 删除四类对象（方块、隐藏箭头、生成器、销毁器） |
| G2 | **小球属性可表驱动**：下方数据表每一行一个小球；列可自定义；`颜色 / 重量 / 大小(半径)` 三列必修；**表不含位置列** |
| G3 | **非球对象可表展示**：另表展示方块 / 箭头 / 生成器 / 销毁器的性质；表改必须真实打进运行时场景 |
| G4 | **生成↔销毁默认闭环**：小球被销毁器消除后，默认在**随机一个生成器**处以**同一 id** 重生（属性按销毁器 / 生成器规则改写） |
| G5 | **一切操作皆指令**：编辑与仿真动作全部走指令总线，控制台可手输驱动；不破坏 AppShell 三条架构不变量 |
| G6 | **只改自由区**：实现落在 `src/App`（及新建业务子目录），不触碰 AppShell.Core / Services / Shell 冻结区 |
| G7 | **运行时权威**：场景与小球运动状态以内存中的运行时世界为准；SQLite 只做属性展示/编辑投影，不做后端式双写权威 |

### 1.3 非目标（v1.3 明确不做）

- **不做任何视频相关**：录制、导出、时间轴、预览窗、相机、字幕音轨——包括占位 UI 与「以后这里是视频」文案（很后期再开专项）。
- 不做完整「对战积分 / 胜负 UI」（可先留自定义属性列，不实现规则引擎）。
- 不做 3D 渲染；落球区为 2D。
- 不做网络联机、账号、商城。
- **不引入第三方物理引擎**（Box2D / Velcro / 等）；自研最小 2D 物理即可。
- **不把小球位置 / 速度写入数据库**；不做「库与场景双权威」同步架构。
- 不改 AppShell 指令语法、DockingHost、Core 公共契约（见演进手册 §3）。
- 不把演示用的 `motor.*` / `debug.*` 当成产品功能保留（可删，不计入验收）。

### 2.3 权威模型（v1.3 定稿 · 极重要）

```
                    ┌──────────────────────────────┐
   唯一权威 ───────▶│  Runtime SceneWorld（内存）    │
                    │  对象图 · 位置 · 速度 · 物理   │
                    │  重力场 · 生成/销毁管线         │
                    └──────────────┬───────────────┘
                                   │
           ┌───────────────────────┼───────────────────────┐
           ▼                       ▼                       ▼
     落球区画布               属性投影表(SQLite)         场景快照文件
     （只读视图+                仅性质列；               （save/load
      手势→指令）              无小球 x/y/vx/vy）         时读写）
```

| 层 | 角色 | 禁止 |
|---|---|---|
| **Runtime SceneWorld** | 场景与仿真的**唯一权威** | — |
| **SQLite 投影表** | 给表窗口看/改**性质**；改完必须同步进 Runtime | 当后端；存小球位置/速度；与 Runtime 双写抢权威 |
| **场景快照文件** | 显式 `scene.save` / `scene.load` 时的序列化进出口 | 运行中每帧写盘；与库互相同步成第三条权威 |
| **指令总线** | 一切写入 Runtime（及必要的投影刷新）的唯一通道 | UI/表控件绕过指令直接改 Runtime 或只改库不改场景 |

**为什么不用「库权威」**：把场景当互联网后端那样「库为准、多端同步」会引入双写、回环、去抖竞态、位置刷库等一堆问题；本产品是本地游戏，**运行时内存即真相**。

### 2.4 分层：模板只读，业务在 App

```
┌─────────────────────────────────────────────────────────────┐
│  WBall 应用扩展层（★ 唯一允许大改 / 新建）                      │
│    DropZone · SceneWorld · 最小物理 · ball/scene/sim 指令      │
│    属性投影同步 · 面板 JSON · 默认布局 · 应用名                 │
├─────────────────────────────────────────────────────────────┤
│  AppShell 标准窗口 + 指令核心 + 服务（只读，经公开接口使用）      │
└─────────────────────────────────────────────────────────────┘
```

铁律回顾（《模板需求》§3.2 + 演进手册）：

1. UI 只发指令，不直接改权威状态绕过总线；
2. 关掉落球区以外的窗口，仅靠控制台仍能放置对象、改属性、启停仿真；
3. 工具窗口关闭 = 隐藏。

若某需求「不改冻结区就做不到」→ 按演进手册 §6 **上报**，不得先斩后奏。

### 2.5 建议工程落点（实现阶段参考）

| 位置 | 职责 | 变更权限 |
|---|---|---|
| `src/App/` | 改名 WBall、装配 `ShellConfig`、注册指令、投影表 schema、默认面板 | ✅ 自由区 |
| `src/App/DropZone/`（建议新建） | 落球区画布、工具交互、对象渲染 | ✅ 自由区 |

## 3. 术语表

| 术语 | 含义 |
|---|---|
| **落球区（Drop Zone）** | 左/中央可编辑的 2D 舞台；放置静态与逻辑对象，小球在此运动 |
| **SceneWorld** | 运行时场景世界（内存）；v1.3 的**唯一权威状态** |
| **场景对象（Scene Object）** | 方块、隐藏箭头、生成器、销毁器 |
| **方块（Block）** | 固体障碍；与小球碰撞 |
| **隐藏箭头（Gravity Arrow）** | 编辑态可见、仿真态默认隐藏；贡献局部重力向量 |
| **小球生成器（Spawner）** | 生成/重生落点；可在生成时打属性补丁 |
| **小球销毁器（Despawner）** | 触发销毁→重生管线；可在销毁时打属性补丁 |
| **小球（Ball）** | SceneWorld 中的运行时实体；投影表 `balls` 一行对应其**性质**（不含位置） |
| **属性投影表** | SQLite 中仅用于展示/编辑性质的表；不是权威 |
| **仿真（Simulation）** | 对 SceneWorld 的时间推进 |
| **g** | 重力强度约定单位；全局初始为向下 **10g**（见 §7.1） |

## 5. 落球区功能需求（v1.3 核心）

优先级：**P0** 本版必须 ｜ **P1** 本版尽量 ｜ **P2** 可后置

### 5.1 画布与坐标系（已定稿）

| 编号 | 需求 | 优先级 |
|---|---|---|
| DZ-01 | 落球区为矩形 2D 世界；**原点在左上角，+X 向右，+Y 向下**（与多数 2D UI 一致）；单位为逻辑像素 | P0 |
| DZ-02 | 支持缩放与平移（编辑导航）；仿真坐标系不因视图缩放改变 | P0 |
| DZ-03 | 网格吸附（可开关）；默认开，步长可配 | P1 |
| DZ-04 | 中央区尺寸变化时画布正确响应（《模板需求》M-04） | P0 |
| DZ-05 | 编辑态显示隐藏箭头；仿真态箭头默认不可见 | P0 |

> 因 +Y 向下，「向下的重力」在坐标上为 **+Y 方向**（见 §7.1）。

### 5.2 手动添加 / 编辑场景对象

| 编号 | 需求 | 优先级 |
|---|---|---|
| DZ-10 | **添加方块**：工具放置；可改位置、尺寸；旋转 P1 | P0 |
| DZ-11 | **添加隐藏箭头**：指定方向；编辑态可见，仿真态默认隐藏 | P0 |
| DZ-12 | **添加小球生成器**：可配置生成属性补丁（§6.3） | P0 |
| DZ-13 | **添加小球销毁器**：可配置销毁属性补丁（§6.3） | P0 |
| DZ-14 | **选择 / 移动 / 删除**；危险删除可走 ConfirmPrompt | P0 |
| DZ-15 | 框选 P1；多选对齐 P2 | P1/P2 |
| DZ-16 | 添加/移动/删除/改属性最终生成指令并回显；**先改 SceneWorld，再刷新投影表** | P0 |
| DZ-17 | 撤销 P2；指令历史 / `run` 重放 P1 | P1/P2 |

### 5.3 小球运行时行为（落球区内）

| 编号 | 需求 | 优先级 |
|---|---|---|
| DZ-20 | 仿真开启后受重力场影响；全局初始 **向下 10g** + 箭头矢量合成（§7.1） | P0 |
| DZ-21 | 小球与方块碰撞：不穿透；自研最小响应即可 | P0 |
| DZ-21b | **球-球碰撞本版必做**，并提供**开关**（指令 + 面板）；关闭时球可重叠穿过彼此，仍与方块/生成销毁交互 | P0 |
| DZ-22 | 进入销毁器 → 销毁管线（§6.4） | P0 |
| DZ-23 | 从生成器位置（或配置出生点）出现 | P0 |
| DZ-24 | **默认重生**：随机生成器 + **同 id 传送**；无生成器则真正移除 + Warn | P0 |
| DZ-25 | **播放 / 暂停 / 重置**；重置按 SceneWorld 的可恢复初始态重建运行时小球（位置不来自库） | P0 |
| DZ-26 | `sim.seed` 固定随机（含随机选生成器）；P1 | P1 |

### 5.4 表窗口与 SceneWorld 的关系（定稿）

**原则：表少改，但改了绝不能只改库不改场景。**

| 编号 | 需求 | 优先级 |
|---|---|---|
| DZ-30 | 每个存活小球在 `balls` 投影表有一行，**仅性质列**（见 §6.1）；**禁止** `x/y/vx/vy` 列 | P0 |
| DZ-31 | 表窗口或 `db.update` / `ball.set` 改性质 → **必须写入 SceneWorld 对应球**，画布立即（或短去抖）反映；再写回投影行（若尚未一致） | P0 |
| DZ-32 | `scene_objects` 投影展示非球对象性质；改表（含位置/尺寸/方向等若作为列暴露）→ **必须写入 SceneWorld**，画布同步 | P0 |
| DZ-33 | 自定义列可增删（必修三列不可删）；增删后 SceneWorld schema 与投影表、补丁校验一致 | P0 |
| DZ-34 | 仿真过程中小球位置高频变化：**不得**因此更新数据库；投影表不显示位置 | P0 |
| DZ-35 | 禁止「只更新 SQLite、等某次刷新再读回场景」的后端式链路；测试用例须覆盖：改表后暂停再播放，性质仍以改后为准且与画布一致 | P0 |

推荐实现路径（规范，非强制代码结构）：

1. 表编辑 / `db.*` 经总线拦截或 `ball.set` / `scene.set` 统一入口；
2. Handler **只以 SceneWorld 为写入目标**；
3. 成功后再 `UPSERT` 投影行（性质字段），供表窗口显示；
4. 若有人手输 `db.update` 改了投影表，须有拦截器：**把变更应用到 SceneWorld**，或拒绝并提示改用 `ball.set`（二选一时优先「应用到 SceneWorld」，避免静默只改库）。

## 6. 数据模型与属性系统

### 6.1 小球性质投影表（`balls`）

**每一行 = 一个小球的性质镜像；不是运动状态存储。**

#### 6.1.1 系统列

| 列名 | 类型 | 说明 |
|---|---|---|
| `id` | TEXT/INTEGER | 与 SceneWorld 小球 id 一致（重生同 id） |
| `alive` | INT | 可选；1 存活 / 0 已真正移除。传送重生保持 1 |

#### 6.1.2 禁止出现的列

| 列名 | 说明 |
|---|---|
| `x`, `y` | **禁止入库**；仅存在于 SceneWorld |
| `vx`, `vy` | **禁止入库**；仅存在于 SceneWorld |

#### 6.1.3 必修业务列

| 列名 | 类型 | 说明 | 画布 / 物理映射 |
|---|---|---|---|
| `color` | TEXT | 颜色（建议 `#RRGGBB`） | 填充色 |
| `weight` | REAL | 重量 | 加速度 / 碰撞质量 |
| `size` | REAL | **半径**（不是直径） | 显示与碰撞半径 |

> 创建 / 删除列的指令不得删除这三列。

#### 6.1.4 自定义列

- 可增：`team`, `hp`, `label`, `score`…（TEXT / REAL / INT）
- 生成器 / 销毁器补丁可读写
- 补丁未提及的列：重生时**继承销毁前快照**（定稿）

### 6.2 场景对象投影表（`scene_objects`）

用于展示/编辑非球对象性质。单表 + `type` + `props_json`（常用字段可提升为真列便于筛选）。

| 列名 | 说明 |
|---|---|
| `id` | 与 SceneWorld 一致 |
| `type` | `block` / `arrow` / `spawner` / `despawner` |
| `x`, `y`, `w`, `h` | 可出现在投影表（低频）；**权威仍在 SceneWorld**；改表必须打进场景 |
| 朝向 | `rotation` 或 `dir_x`,`dir_y` |
| `props_json` | 补丁、重力强度、影响半径等 |

> 与小球不同：场景对象位置是编辑态低频数据，允许出现在投影表；但仍禁止「库权威」。

### 6.3 生成器 / 销毁器属性补丁

```json
{
  "set": { "color": "#FF6600", "weight": 1.5 },
  "add": { "score": 1 },
  "unset": ["tmp_flag"]
}
```

**合成顺序（定稿）**：

1. 取销毁前性质快照（来自 SceneWorld，不是读库）；
2. 应用**销毁器** patch；
3. 随机选生成器；
4. 应用**该生成器** patch；
5. **同 id** 将小球放到该生成器位置，更新 SceneWorld；刷新投影表性质行（**不写位置列**）。

同字段两边都 set 时：**生成器覆盖销毁器**。

### 6.4 默认闭环：销毁 → 随机生成器 · 同 id

```
小球进入销毁器
  → 销毁器 patch
  → 若有 ≥1 个生成器：
        随机选一个
        → 生成器 patch
        → 同 id 传送到该生成器位置（速度可清零，定稿：清零）
  → 若无生成器：
        从 SceneWorld 移除 + 投影行删除或 alive=0 + Warn
```

**身份策略（定稿）**：**同 id 传送（原 R1）**。不做 R2 新 id（除非将来单对象选项另开需求）。

### 6.5 表修改 → 场景的强制通路（防 bug 专节）

| 写入来源 | 正确行为 | 错误行为（验收失败） |
|---|---|---|
| 表窗口改 `color` | `ball.set`（或等价）→ SceneWorld → 画布变色 → 投影一致 | 只 `UPDATE balls` 画布不变 |
| 手输 `db.update` 改 `weight` | 拦截后应用到 SceneWorld，或拒绝并提示 `ball.set` | 库已改、仿真仍用旧 weight |
| 销毁/生成改了性质 | SceneWorld 先变 → 投影刷新 | 只改库或只改内存不同步 |
| 仿真中球在动 | 仅 SceneWorld 更新位置 | 向 DB 写 x/y |

## 7. 物理与重力（自研最小集 · 定稿）

### 7.1 重力场

- **全局重力（初始状态）**：方向为坐标 **+Y（向下）**，强度 **10g**。  
  - `g` 为游戏内约定常量（实现时在代码/设置中给出数值，例如 `g = 98` 逻辑像素/秒² 则 10g = 980；具体数值可调但不改「10g 向下」语义）。
- **隐藏箭头**：在影响半径内贡献重力向量；**多箭头与全局采用矢量合成**（定稿）：
  1. 在采样点，对每个影响该点的箭头，按距离衰减（如线性或平滑衰减）得到向量贡献；
  2. 将所有箭头贡献与全局重力向量 **相加**（矢量合成）；
  3. 若某点无箭头影响，则仅受全局 **向下 10g**。
- 箭头仿真态默认不可见；编辑态可见。
- 可用指令 / 面板改全局强度（仍表示「若干 g」），不改变「默认为 10g」的初始值。

### 7.2 碰撞

| 类型 | 要求 |
|---|---|
| 球–方块 | P0；圆 vs AABB（旋转方块 P1） |
| 球–球 | **P0**；弹性或半弹性分离；**必须有开关** `sim.ballcollision`（名可微调，语义不变） |
| 实现 | **自研最小物理**；禁止引入第三方物理库 |

开关：

- 开（建议默认 **开**）：球与球碰撞并交换/分离速度；
- 关：球与球不产生碰撞响应（可重叠），不影响方块碰撞与生成/销毁。

### 7.3 性能粗目标

| 编号 | 需求 | 优先级 |
|---|---|---|
| N-DZ-01 | 约 200 球 + 50 场景对象，可交互（目标 ≥30 FPS） | P1 |
| N-DZ-02 | **位置永不写库**；性质变更才更新投影；禁止每帧触库 | P0 |

## 9. 指令系统（派生域）

语法遵守模板 §5.1。

### 9.1 `scene.*`

| 指令 | 要点 |
|---|---|
| `scene.add` | `type=block\|arrow\|spawner\|despawner` + 几何与类型参数 → SceneWorld → 刷新投影 |
| `scene.remove` / `scene.move` / `scene.set` | 只写 SceneWorld，再刷新投影 |
| `scene.list` | 读 SceneWorld |
| `scene.clear` | 需确认 |
| `scene.save` / `scene.load` / `scene.new` | 文件 ↔ SceneWorld |

### 9.2 `ball.*`

| 指令 | 要点 |
|---|---|
| `ball.spawn` | 在生成器或坐标创建；写 SceneWorld；投影插入性质行 |
| `ball.despawn` | 走销毁管线或真正移除 |
| `ball.set` | **改性质的主指令**；写 SceneWorld 再刷新投影 |
| `ball.list` | 摘要（可含位置——仅控制台输出，不入库） |
| `ball.prop.add` / `ball.prop.remove` | 自定义列；remove 拒绝三必修列 |

> 表窗口改单元格应生成 `ball.set` / `scene.set`。若暴露 `db.update`，必须带「应用到 SceneWorld」语义（§5.4 / §6.5）。

### 9.3 `sim.*`

| 指令 | 要点 |
|---|---|
| `sim.play` / `sim.pause` / `sim.reset` | 播放控制 |
| `sim.step` | 单步（P1） |
| `sim.seed` | 随机种子 |
| `sim.ballcollision` | `on=true\|false`（或 `value=`）；球-球碰撞开关 |
| `sim.gravity` | 查看/设置全局重力（默认 10g 向下） |
| `sim.status` | 状态摘要 |

### 9.4 面板 JSON

`panels/dropzone.json` 建议包含：

- 工具：方块 / 箭头 / 生成器 / 销毁器 / 选择
- 仿真：播放、暂停、重置
- **球-球碰撞**开关
- 全局重力强度（g 倍数）
- 保存 / 加载场景

移除产品默认中的 `motor.json` 种子。

## 13. 验收标准（v1.3 可勾选）

> 与 §11 阶段出口对应；**D5 结束时本表须全部勾选**。

1. **放置四类对象**：鼠标工具各添加至少一个；控制台有 `scene.add` 回显；SceneWorld 与画布一致。 → *D1*
2. **隐藏箭头**：编辑态可见、仿真态默认不可见；改变方向后运动趋势明显变化（矢量合成生效）。 → *D3*
3. **坐标系**：左上原点、+Y 向下；无箭头时小球受 **向下 10g** 加速。 → *D1 坐标 + D2 重力*
4. **必修三列**：`color` / `weight` / `size`（半径）；尝试删除被拒绝；**表中无 x/y/vx/vy**。 → *D4*
5. **自定义列**：新增列可被补丁写入；重生后表中值正确（同 id）。 → *D4（依赖 D3 补丁）*
6. **表改打进场景**：改 `color`/`size`/`weight` 后画布与物理立即一致；再 `sim.pause`/`play` 不回退；手输改表路径不出现「只改库」。 → *D4*
7. **对象表**：列出非球对象；改位置/性质后画布与 SceneWorld 一致。 → *D4*
8. **默认闭环**：销毁后同 id 出现在随机生成器处；无生成器则移除 + Warn。 → *D3*
9. **补丁顺序**：同字段最终以生成器为准。 → *D3*
10. **球-球碰撞**：开启时相撞分离；关闭时重叠穿过；开关有面板与指令。 → *D5*
11. **控制台完备性**：仅手输指令可完成放置、仿真、改性质、切换球球碰撞、存取场景。 → *D5（子集从 D1 起累计）*
12. **场景存取**：save/load 恢复对象与设置；hydrate 来自文件→SceneWorld。 → *D5*
13. **无位置写库**：仿真后检查 DB，`balls` 无位置列且无位置写入。 → *D2 起遵守，D4/D5 核查*
14. **无第三方物理库**；**无视频相关 UI/指令**。 → *全程 / D5 终检*
15. **冻结区纪律**：不改 AppShell.Core/Services/Shell 契约与 DockingHost（除非已上报获批）。 → *全程*

## 15. 风险与合规

| 风险 | 说明 | 应对 |
|---|---|---|
| 表改不同步场景 | 最易出「偶发 bug」 | §6.5 强制通路 + 验收 6 |
| 误把位置写库 | 性能与权威混乱 | schema 无位置列；代码审查禁止 |
| 库 hydrate 场景 | 后端式双权威 | load 只从文件→SceneWorld |
| 重型物理库 | 过重、依赖升级 | 禁止；自研最小集 |
| 视频范围膨胀 | 分心 | 非目标写死；验收 14 |
| 误改冻结区 | — | 演进手册 §6 |
| 新 NuGet（如 SkiaSharp） | 须确认 | 开工前向用户确认渲染依赖 |
