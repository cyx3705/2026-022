## 0. 一句话定义

**v2.11**：大球**显示剩余数值**并随啃格实时递减；新增**小球弹药库**——小球/齐射/直射三槽共池蓄弹，**出球方式跟随最后一次落槽切换**（小球=沿炮管点射、齐射=无视炮管 360° 环射、直射=炮管定格一段时间集中倾泻）；**取消激光球**；大球之间**按动量碰撞**、发射动量适度随机；舞台**锁定 16:9 长宽比**为视频输出定版。

## 1. 功能需求

### 1.1 大球数值显示（P0）

| 编号 | 需求 |
|---|---|
| BV-01 | 领地弹丸中心显示**剩余占领数**（=CapturesLeft，K/M 格式）；随啃格逐步减小，啃完弹消数值归零 |
| BV-02 | 仅在弹体够大时显示（半径 ≥8px），数值 1 的最小弹不标 |

### 1.2 小球弹药库与三模式（P0）

| 编号 | 需求 |
|---|---|
| SA-01 | 阵营新增**小球弹药库**（数值池）：落入 `小球`/`齐射`/`直射` 槽的数值全部累入该池（不再入大球队列） |
| SA-02 | **模式跟随最后落槽**：最后一次落入哪个槽，出球方式即切换为该槽模式 |
| SA-03 | `小球` 模式：每射击节拍沿炮管方向点射一小簇（≤4 发/拍，小散布），每发数值 1、一格大 |
| SA-04 | `齐射` 模式：**无视炮管**，每拍以 360° 均匀环射一圈（≤12 发/拍） |
| SA-05 | `直射` 模式：**炮管停转定格**，定格时长按该次落球积分而定（`clamp(value/16, 1, 12)` 秒，可叠加封顶）；期间沿定格方向密集直喷（≤4 发/拍，极小散布） |
| SA-06 | 池空则小球停射；大球队列（大球/散弹/中子星/散血球/RUN 槽）照旧独立发射 |

### 1.3 取消激光球（P0）

| 编号 | 需求 |
|---|---|
| LZ-01 | 从内置武器表（WeaponCatalog / ScenarioStore 示例）与 Demo 场景结算槽中移除 `激光球`；底部槽变五格全宽 |
| LZ-02 | 旧配置里残存的激光球结算按未知槽 Fail-safe 处理（仅传送 + Warn，v1.6 语义现成） |

### 1.4 大球动量物理（P0）

| 编号 | 需求 |
|---|---|
| MO-01 | 大球质量 = 其数值（越大越重）；球-球碰撞沿用自研物理的动量交换 → **越大越快的球动量越大**，小球撞大球被弹开 |
| MO-02 | **发射动量随机（适度）**：出膛速度乘确定性随机系数（约 ±25%），并随数值增大略微放慢（重弹慢而沉） |

### 1.5 出片比例锁定（P0）

| 编号 | 需求 |
|---|---|
| AR-01 | 舞台内容区**锁定 16:9**：窗口任意比例下内容区信箱式居中（黑边补齐），录制帧与预览观感一致 |
| AR-02 | 比例值挂 StageState（默认 16:9），后续可指令化 |

## 2. 验收标准

1. 数值 ≥2 的弹丸中央可见数字，啃格时数字递减至消失。
2. 连续落球：落小球槽→炮管点射；落齐射槽→立即改为 360° 环射；落直射槽→炮管定住 N 秒集中喷射后恢复旋转。
3. 武器表/Demo 槽内无激光球；大球互撞可见大弹推开小弹；同源出膛速度有肉眼可辨差异。
4. 主窗口拉宽/拉高时舞台保持 16:9 居中黑边。
5. 60 秒无头验证通过（含确定性）；构建零警告；版本 **2.11.0**。
