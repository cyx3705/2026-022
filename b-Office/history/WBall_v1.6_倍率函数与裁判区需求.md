## 0. 一句话定义

**v1.6** 把落球编辑器推进到可玩的**核心演示**：每个小球带**居中标号（倍率）**；销毁区用可编辑的 **name=变换函数**（如 `X5` / `RUN`）在传送时改写倍率并瞬移到生成区；**重量/大小由倍率经表头公共行公式驱动**；另设**裁判区**按阵营（颜色）管理初始球数、积分与代表色。顺带修正 v1.5 异形半透明，使异形填充与方块**完全同色不透明**。

## 1. 背景与产品意图

v1.5.x 已具备：落球舞台、方块/异形、生成器/销毁器传送、尾迹、场景窗、调试窗。  
v1.6 要演示的核心玩法是：

```
球带倍率标号 → 掉进「函数销毁区」→ 倍率按 name 变换 → 瞬移回生成区
                 → 掉进「RUN 销毁区」→ 倍率兑现为阵营积分 → 球重置为初始并重生
重量/大小随倍率变化 → 视觉上「倍率越大球越大/越重」
裁判表记录各颜色阵营的积分与开局配置
```

这是一次**玩法层大更新**，但仍遵守：运行时权威、位置不入库、指令回显、无第三方物理库、无视频。

## 2. 目标与非目标

### 2.1 目标

| 编号 | 目标 |
|---|---|
| G1 | 每个球**居中显示标号**；初始标号/倍率 = **1** |
| G2 | 销毁器：**无边框方形**；内部可编辑 **name**（变换函数名） |
| G3 | 支持函数族 **`Xn`**（如 `X5`=`倍率×5`）与 **`RUN`**（兑现积分并重置重生） |
| G4 | name 的赋予 = 重命名/赋值；**必须有等价指令**（命令行可驱动） |
| G5 | 球的 **weight / size 与倍率关联**；关联式由**表窗口公共行（Excel 风）**配置，非新面板 |
| G6 | 公共行 = 新建球/方块等的**默认初始状态**来源之一 |
| G7 | **裁判区 + 裁判表**：按阵营列管理初始球数、积分、代表颜色等 |
| G8 | 修正异形半透明：**与方块同色且不透明**（v1.5 小 bug） |
| G9 | 不破坏 v1.5 传送/尾迹语义；函数触发仍走**同实例瞬移** |

### 2.2 非目标（v1.6）

- 不做完整脚本语言 / 任意表达式解析器（先固定 `Xn` + `RUN`，可扩展表见 §9）  
- 不做联网对战、账号、商城  
- 不做视频录制  
- 不把表窗口改成完整 Excel（仅**顶行公共行 + 字母列/数字行寻址**）  
- 不引入第三方物理库

## 4. 术语

| 术语 | 含义 |
|---|---|
| **标号 / 倍率（Multiplier）** | 球心显示的正数（演示期可用整数）；初始为 1；玩法核心状态 |
| **销毁函数 name** | 销毁器上的字符串标识；命中时对球执行的变换（如 `X5`、`RUN`） |
| **`Xn` 函数** | `X` + 正整数 n：`newMultiplier = oldMultiplier × n`，然后瞬移到生成区 |
| **`RUN` 函数** | 将当前倍率**计入所属阵营积分**，球复位为初始倍率/性质，再瞬移到生成区 |
| **公共行（Public Row）** | 表窗口每个表最上方的特殊行；可用 Excel 式引用；定义默认值与倍率→重量/大小映射 |
| **单元格寻址** | 字母列 + 数字行（如 `B2`）；公共行建议为第 **1** 行或独立行号 `0`/`P`——见 §9 |
| **裁判区 / 裁判表** | 管理各阵营（通常按球颜色）初始配置与运行积分的窗口+表 |
| **阵营（Faction）** | 同代表色的球集合；积分归属该阵营 |

### 5.2 销毁器：无边框 + name 函数

| 编号 | 需求 | 优先级 |
|---|---|---|
| DP-01 | 销毁器视觉：**无边框**方形填充（可半透明底以便看见内部文字）；与「实体方块」区分 | P0 |
| DP-02 | 销毁器中心显示可编辑 **name** 文本（置中） | P0 |
| DP-03 | 画布选中销毁器后：可键盘输入/对象调试窗/表窗口改 name | P0 |
| DP-04 | **name 即函数**；重命名 = 赋予函数；必须进指令集（见 §6） | P0 |
| DP-05 | 球命中销毁器：先解析 name → 执行函数 → **同实例瞬移**到随机生成器（无生成器则告警并按既有策略移除） | P0 |
| DP-06 | 未知 name：Fail 安全——不改倍率或仅传送并 `Warn`（默认建议：**拒绝变换只传送并警告**）——见 §9 | P0 |
| DP-07 | 生成器仍可保留；本版不强制生成器也有 name | P1 |

#### 5.2.1 函数：`Xn`

| 编号 | 需求 | 优先级 |
|---|---|---|
| FN-X1 | 语法：`X` + 正整数，大小写不敏感（`x5`=`X5`） | P0 |
| FN-X2 | 语义：`Multiplier ← Multiplier × n`（例：原 2，进 `X5` → 10） | P0 |
| FN-X3 | 然后瞬移到生成区；尾迹/残影沿用 v1.5.2 | P0 |
| FN-X4 | 变换后立即按公式刷新 **weight / size**（§5.3） | P0 |
| FN-X5 | n 非法（0、非数字、空）→ 视为未知函数 | P0 |

#### 5.2.2 函数：`RUN`

| 编号 | 需求 | 优先级 |
|---|---|---|
| FN-R1 | name 等于 `RUN`（大小写不敏感）时触发 | P0 |
| FN-R2 | 将球**当前倍率**加入其阵营积分（阵营由球颜色映射，见裁判表） | P0 |
| FN-R3 | 球恢复**初始状态**：倍率=初始值（通常 1）、weight/size 按初始倍率重算；颜色等是否重置见 §9 | P0 |
| FN-R4 | 然后瞬移到生成区（同传送） | P0 |
| FN-R5 | RUN 是「结算入口」；演示文案：RUN 激活后标号值即本段积分贡献 | P0 |

### 5.3 倍率 ↔ 重量 / 大小（表头公共行）

> 用户定调：**不新开控制面板**；在**表窗口所有表格最顶上**加公共行；Excel 风用**字母列+数字行**引用；公共行也是新建对象的初始默认。

| 编号 | 需求 | 优先级 |
|---|---|---|
| PR-01 | 每个投影表（至少 `balls`，建议 `scene_objects` / 其它表一并）顶部增加 **公共行（Public Row）** | P0 |
| PR-02 | 公共行可手动编辑；改后影响：**新建**球/对象的默认字段，以及倍率驱动公式的参数 | P0 |
| PR-03 | 单元格寻址：列用字母（A,B,C…），行用数字；公共行占用约定行号（建议 **行 1 = 公共行**，数据从行 2 起；或行号 `0` 专指公共行——§9 定稿） | P0 |
| PR-04 | 球的 weight、size 由公式计算，公式可引用公共行单元格与当前倍率，例如： | P0 |

**建议默认公式（可改，写入公共行或固定槽位）：**

| 量 | 建议关系（演示默认） |
|---|---|
| `size`（半径） | `size0 + kSize × (multiplier - 1)` 或 `size0 × multiplier` |
| `weight` | `weight0 + kWeight × (multiplier - 1)` 或 `weight0 × multiplier` |

其中 `size0` / `weight0` / `kSize` / `kWeight` 存在公共行对应列（用户可改数字）。

| 编号 | 需求 | 优先级 |
|---|---|---|
| PR-05 | 倍率变化后（含 `Xn`）**自动重算** weight/size，并刷投影 | P0 |
| PR-06 | 用户若在表里**直接改**某球 weight/size：演示期建议 **允许但下次倍率变化会覆盖**；或只读并由公式驱动——见 §9 | P0 |
| PR-07 | 公共行改 `size0` 等：已存在球是否立即全体重算——默认 **仅影响新建 + 后续倍率变化**；可选「应用到全部」指令 | P1 |
| PR-08 | 寻址指令（可选）：`table.get ref=B1` / 面板不强制；表 UI 点击单元格编辑为主 | P1 |
| PR-09 | **冻结区风险**：表窗口若属 Shell 谨慎/冻结区，公共行须优先用 **自由区包装**（自定义 Table 头或 App 侧表增强）；若必须改 Shell 表控件 → **上报** | P0 |

> 实现代理注意：PR-09 是架构风险点；需求允许「App 自绘增强表」或「在投影表之上叠加公共行 UI」，避免先斩冻结区。

## 6. 指令增量（草案，单点语法）

| 指令 | 说明 |
|---|---|

## 10. 验收标准（v1.6 可勾选草案）

1. 异形填充与默认方块同色且**不透明**。  
2. 新球中心显示标号 `1`。  
3. 销毁器无描边，中心可见 name；可改为 `X5`。  
4. 倍率为 2 的球进 `X5` → 标号变 10，瞬移到生成器，尺寸/重量按公式变大。  
5. 球进 `RUN` → 对应颜色阵营 score 增加原倍率，球回初始倍率并传送。  
6. `scene.set`/`despawn.set`（或定稿名）改 name 与 UI 一致，控制台可重放。  
7. 表窗口顶部有公共行；改公式参数后新建球或倍率变化行为符合预期。
