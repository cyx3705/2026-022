# WBall · v2.12.3 补丁需求 —— 去血量、弹药占比环与火力联动

> 文档性质：补丁需求（基线 v2.12.2）。 日期：2026-07-26 ｜ 版本：**2.12.3**

## 1. 需求

| 编号 | 需求 |
|---|---|
| NB-01 | **取消血量概念**：炮台生存只看「护罩 + 本垒格」（本垒被推平即亡,v2.9 规则不变）;内圈不再显示血量/领地占比 |
| NB-02 | **内圈 = 弹药占比环**：本方总弹药(小球池 + 大球队列数值和)占**四方总弹药**的比例;弹药此消彼长时环随之伸缩 |
| NB-03 | **火力随弹药加猛**（解决"弹药永远打不完"）:小球射速 = 6+0.15×池值 发/秒(封顶 90,直射定格再×2 封顶 150);大球出膛间隔 = 基础间隔 ÷ (1+队列长×0.25),下限 0.08s |
| NB-04 | 炮台下方弹药数字改为 `小球池数值·大球队列数值和`(打出去即减,随 NB-03 可见涨落) |
| NB-05 | **顶部计分条动态宽度**：四盒宽度按各方**领地占比**分配(最小宽 90px 防文字挤坏),战争进度一目了然;文字改为 `PTS · 领地 · 弹药` |

## 2. 验收

1. 内环 = 弹药份额,四方互相攻防时环肉眼可见涨落;弹药大量囤积时该方火力显著变猛,弹药能被打空。
2. 炮台下弹药数字随开火递减、随落球递增。
3. 顶部四盒宽度随领地优劣势实时伸缩,劣势方保持最小宽度可读。
4. 60 秒无头验证通过(同种子哈希一致);构建零警告;版本 **2.12.3**。
