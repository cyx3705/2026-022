# WBall · v2.12.5 补丁需求 —— 破盾直入与落球区暗色美化

> 文档性质：补丁需求（基线 v2.12.4）。 日期：2026-07-26 ｜ 版本：**2.12.5**

## 1. 需求

| 编号 | 需求 |
|---|---|
| BS-01 | **破盾直入**（修"大球碰炮塔无敌"）：大球撞护罩把护盾打穿（Shield→0）时**不再反弹**，带剩余数值继续压向炮台本体 → 触杀链路贯通；护盾未破时才反弹（v2.12.2 语义保留） |
| BE-01 | **落球区暗色主题**：内区底色改暗（#0B0E13）、网格线弱化、边墙改金色描边（参考视频观感） |
| BE-02 | **槽位按语义配色**：`Xn` 倍率门统一金色；攻击槽按武器色（大球橙/小球天蓝/护盾青/直射紫/齐射绿/散弹粉/中子星紫罗兰/散血球红/RUN 白）；槽名改白色粗体居中 |
| BE-03 | 界外区域/钉阵同步暗色化（钉=浅灰蓝）；生成器/球体/标号/选中手势等既有视觉不回归 |

## 2. 验收

1. 大球把护盾磨到 0 的那一发不再弹开，followed 触杀成立；整局收敛速度不劣于 v2.12.4。
2. 左侧落球区为暗底金边、槽位彩色白字，与右侧战场观感统一。
3. 全局无头验证通过（同种子哈希一致）；构建零警告；版本 **2.12.5**。
