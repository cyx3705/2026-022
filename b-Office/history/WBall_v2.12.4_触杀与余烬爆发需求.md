# WBall · v2.12.4 补丁需求 —— 炮台触杀、余烬爆发与新淘汰判定

> 文档性质：补丁需求（基线 v2.12.3）。 日期：2026-07-26 ｜ 版本：**2.12.4**

## 0. 背景

v2.12.3 后炮台近乎无敌：本垒格死法依赖弹丸深入腹地啃到特定格,护罩+弹价值消耗让这几乎不发生。本补丁改为**直接触杀**并引入**余烬爆发**,保证每局必出唯一胜者。

## 1. 需求

| 编号 | 需求 |
|---|---|
| TK-01 | **触杀**:护罩失守(Shield=0)后,**任意敌球(大小皆可)触碰炮台本体即摧毁**;护罩在时仍由护罩拦截(v2.12.2 规则) |
| TK-02 | 旧"本垒格陷落"死法**退役**(触杀取代) |
| TK-03 | **余烬爆发**:炮台被摧毁时,该队**左侧落球区的同色球**(带各自倍率数值)与**弹药库全部存货**(大球队列逐发+小球池合一发)统统转化为**大球**,从炮台原位向 360° 随机方向射出,继续作战 |
| TK-04 | 阵亡方左侧断粮、炮台消失(既有);**其余烬大球仍可啃地、对消、触杀敌台** |
| TK-05 | **淘汰判定**:炮台亡**且**场上已无该队弹丸 → 该队淘汰;活跃方(炮台在或余弹在)只剩一家 → 胜者;全灭 → 平局 |
| TK-06 | 全程确定性;direct 旧模式不受影响 |
| TK-07 | **决胜时刻**(默认 240s,`arena_layout.json.suddenDeathAtSeconds`):此后护盾停止一切补给(护盾槽结算**转喂小球弹药**、回流转化关闭、再生停止),只降不升 ⇒ 战局必然收敛出胜者 |
| TK-08 | 连带修复:底部结算槽高 70→120(高倍巨球半径可超 70,球心进不了槽判定区曾堵死整个经济);引导钉转 45° 菱形(防球搁置钉顶) |

## 2. 验收

1. 护盾磨光后一颗小球贴脸即可斩台;斩台瞬间可见一团大球从原位炸散(数值=原经济球倍率/弹药存量)。
2. 阵亡方余烬大球继续推地甚至反杀;余烬耗尽该方才从活跃名单消失。
3. 一局必然收敛到唯一胜者(或全灭平局);60 秒无头验证(同种子哈希一致)通过;构建零警告;版本 **2.12.4**。
