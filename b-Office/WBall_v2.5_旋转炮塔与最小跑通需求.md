## 0. 一句话定义

**v2.5** 是对 v2.0 的一次**观感与人机交互修正**：把炮台从「隐形直瞄」改为**参考视频同款的匀速旋转炮管**——炮管以恒定角速度转动，转到哪就往哪打；并保证**开箱最小跑通**：启动应用 → 左落球区 + 右对战舞台即所见 → 一条指令开打整局。

背景：v2.0 之前的实现（grok4.5 时期）代码质量、页面设计与交互均不达标；v2.0 重建了架构骨架，但炮台开火仍是"瞬间锁定目标直射"，右侧战场缺少参考视频里最有辨识度的**旋转炮塔**动态观感。v2.5 修正这一点，并作为后续观感打磨（粒子团、拖尾、飘字）的地基。

## 1. 目标与非目标

### 1.1 目标

| 编号 | 目标 |
|---|---|
| G1 | **匀速旋转炮管**：每座炮台一根可见炮管，以恒定角速度（RPM 可配）持续旋转；开火方向 = 炮管当前指向 |
| G2 | **spin 成为默认瞄准模式**：v2.0 的 highestHp/nearest/rotate/lowestHp 保留可切换；新装默认 `spin` |
| G3 | **炮管可视化**：旋转肉眼可见（圆头粗管 + 炮口亮点），保持现有光晕/暗底观感 |
| G4 | **确定性不破**：炮管角是种子无关的纯时间函数（初始角 + RPM×时间），纳入 `determinism.check` 哈希 |
| G5 | **最小跑通**：启动即见「左落球区 + 右战场」合成舞台；`demo.play` 一条指令跑完整局到分胜负 |
| G6 | **零回归**：v2.0 全部指令/配置/录制路径不变；老配置文件可平滑升级 |

### 1.2 非目标（v2.5 划界）

- 不做粒子团炮台、拖尾、伤害飘字等深度观感（留给 v2.6+）；
- 不动武器库语义、经济桥映射、录制后端；
- 不引入任何新依赖；不碰 Shell 冻结区。

## 2. 功能需求

### 2.1 旋转炮管（P0）

| 编号 | 需求 |
|---|---|
| RB-01 | 炮台运行时新增 `BarrelAngleDeg`（当前炮管角，度）与 `BarrelRpm`（转速，转/分钟） |
| RB-02 | 初始角：**指向战场中心**（按象限确定，确定性）；开局 `Reset` 时重置 |
| RB-03 | 导演每固定步进推进：`angle += rpm × 6 × dt`（RPM→度/秒 = rpm×6），对 360 取模；只有存活炮台转动 |
| RB-04 | `targeting=spin`（新默认）：`Fire` 的发射方向 = 炮管当前角；散布/弹数/伤害等火力语义不变 |
| RB-05 | 旧瞄准模式（highestHp/nearest/rotate/lowestHp）保留，`arena.targeting` 可随时切换 |
| RB-06 | `BarrelRpm` 每炮台可配（`turrets.json` 字段 `barrelRpm`，默认 6；范围 0.5~60），运行时 `turret.set rpm=` 可改 |
| RB-07 | 炮管角纳入 `BattleDirector.DeterministicHash`，同种子同剧本逐帧一致 |

### 2.2 炮管可视化（P0）

| 编号 | 需求 |
|---|---|
| VZ-01 | `ArenaView` 在炮台圆体上叠画炮管：自圆心沿 `BarrelAngleDeg` 方向伸出约 1.8×半径的圆头粗线（阵营色加亮），末端一枚炮口亮点 |
| VZ-02 | 死亡炮台不画炮管；光晕/卡片/血条等既有绘制不变 |
| VZ-03 | 播放/录制态下随导演步进逐帧刷新（复用现有 `NotifyChanged` 通道，不加新计时器） |

### 2.3 指令与配置增量（P0）

| 域 | 指令 | 说明 |
|---|---|---|
| arena. | `arena.targeting [mode=]` | 查询/设置瞄准模式：`spin`（默认）/highestHp/nearest/rotate/lowestHp；落盘 `arena_layout.json` 并重置战场 |
| turret. | `turret.set id= rpm=` | 运行时改单炮台转速（0.5~60 RPM） |

配置：`arena_layout.json.targeting` 新装默认 `spin`；`turrets.json` 每条新增 `barrelRpm`（缺省 6）。**升级策略**：旧文件缺 `barrelRpm` 按默认值补；旧默认 `targeting=highestHp` 的种子文件由本次升级一次性改写为 `spin`（用户手改过的其它值不动）。

### 2.4 最小跑通（P0，验收锚点）

启动应用（无需任何面板）：

1. 主内容即 `StageView`：左=Plinko 落球区（黄墙、倍率门、底部结算槽），右=暗底四象限战场，顶部 HUD 计分盒/计时/武器条；
2. 控制台输入 `demo.play seed=42` → 左侧四色球开落、右侧四炮台**匀速旋转**开火互轰 → 分出胜负；
3. `determinism.check`（或两次同种子对局哈希比对）通过。

## 3. 验收标准（可勾选）

1. 四炮台各有可见炮管，以配置转速匀速旋转；转到哪打到哪（spin 模式）。
2. `arena.targeting mode=nearest` 等旧模式仍可用并即时生效。
3. `turret.set id=blue rpm=20` 后蓝方炮管明显加速；`turret.list` 显示 rpm。
4. 同种子两局 `DeterministicHash` 一致（含炮管角）。
5. `demo.play seed=42` 一条指令从冷启动跑到分出胜负；v2.0 既有指令零回归。
6. 构建通过（`DOTNET_EnableWriteXorExecute=0`），无新依赖，未触碰冻结区。
