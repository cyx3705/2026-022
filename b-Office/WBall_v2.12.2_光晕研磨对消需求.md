# WBall · v2.12.2 补丁需求 —— 光晕研磨对消与自家球转化

> 文档性质：补丁需求（基线 v2.12.1）。 日期：2026-07-26 ｜ 版本：**2.12.2**

## 0. 背景

v2.12.1 的对消按"物理贴触"判定，物理引擎分离弹体后判定窗口极窄、高速弹一帧穿越 ⇒ **大球对撞经常不触发**。本补丁整体重写为**光晕接触 + 持续研磨**模型。

## 1. 需求

| 编号 | 需求 |
|---|---|
| HD-01 | **光晕判定**：弹丸外围淡色光晕（渲染半径 1.6×球体）即对消判定区；异色弹光晕相触即进入研磨,范围大、逐帧结算,**保证触发** |
| HD-02 | **同步研磨**：接触期间双方数值每帧**同步等量抵消**;速率随**双方中较大球**的数值定(≈较大值×2/秒,至少 1/帧),单帧扣减不超过较小方余值(1:1 湮灭守恒) |
| HD-03 | **弹体随数值缩小**：数值被磨小/啃格消耗后,球体半径与质量按 `cellSize/2×v^0.25` 同步重算,肉眼可见变小 |
| HD-04 | 推论保持:小球(1)入大球光晕 → 小球湮灭、大球 -1;大球对撞 → 大者快速磨小者,小者尽而大者存余值;小球对撞 → 双灭 |
| HD-05 | **自家小球碰自家护盾 → 转化为护盾**(+5 万/发,不超上限),弹消失 |
| HD-06 | **自家小球碰自家大球 → 融入**:大球数值 +1(尺寸同步长大),小球消失;大球间不融合 |
| HD-07 | 空间分桶步长覆盖最大光晕和(≥160px);全程确定性入哈希 |

## 2. 验收

1. 两颗大球对向发射,光晕相触立刻开始互磨(数字同降、球体同缩),必然触发无漏判。
2. 小球流打大球,大球数字逐发递减;自家齐射圈里的小球碰到自家护罩变成护盾值上涨、碰到自家大球被吸收数字 +1。
3. 60 秒无头验证通过(同种子哈希一致);构建零警告;版本 **2.12.2**。
