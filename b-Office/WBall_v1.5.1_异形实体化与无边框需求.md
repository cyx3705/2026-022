## 0. 一句话定义

**v1.5.1** 纠正实体化语义：封闭线框应变成 **一个异形实体**（内部可用三角形网格拼接表示与碰撞），**不是**一堆彼此独立的正方体/矩形 `block`。同时将 **绘图图形** 与 **实体化结果** 改为 **无描边填充**，使草图/线框与实体在视觉上更好融合。

---

## 1. 问题陈述（v1.5.0 为何错）

### 1.1 现象

v1.5.0 的 `wire.solidify`（方案 A 落地偏差）流程近似为：

```
封闭多边形 → 耳切三角化 → 每个三角形拟合一个旋转 OBB → 多个 type=block
```

结果：用户看到的是 **一堆矩形方块**，而不是「画出的那块异形区域」。  
即使三角形几何上盖住了多边形，**产品语义与编辑体验都错误**（多对象、缝隙感、选中/拉边对「整块异形」无意义）。

### 1.2 根因（规范层）

| 误区 | 正确意图 |
|---|---|
| 把「三角剖分」当成「输出多个矩形 block」 | 三角剖分是 **内部表示**（填充 + 碰撞），对外仍是 **一个异形实体** |
| 用 OBB 近似三角形 | 碰撞/绘制应直接使用 **三角形（或原多边形）**，不要矩形拟合 |
| 实体化产物复用手动 `block` 手势全集 | 异形实体是新类型；手势范围另定（见 §9） |

### 1.3 v1.5.1 要改的两件事

1. **算法/模型**：实体化 → **单一异形实体**（三角拼接实现）  
2. **显示**：绘图图形 + 实体化结果 → **无边框**，便于融为一体  

**本版不写代码**；实现代理按本文落地。

## 2. 目标与非目标

### 2.1 目标

| 编号 | 目标 |
|---|---|
| G1 | 实体化输出 **恰好 1 个** 异形实体（一个 id），外形与闭合线框一致（允许浮点误差） |
| G2 | 异形实体内部用 **三角形拼接（三角网格）** 实现填充绘制与球碰撞 |
| G3 | 球与异形实体碰撞不穿模；自交仍禁止实体化（继承 V5Q4） |
| G4 | **草图折线 / 已提交线框预览 / 异形实体填充** 默认 **无描边**（或仅选中时有轻提示），彼此色块可无缝融合 |
| G5 | 删除/替换 v1.5.0 错误的「多 block OBB」solidify 路径；快照兼容见 §6 |
| G6 | 不引入第三方物理库；不改 AppShell 冻结区 |

### 2.2 非目标

- 不把手动放置的轴对齐/旋转 **矩形 block** 废除（落球工具仍可放方块）  
- 不做布尔运算、挖洞、多重轮廓  
- 不做贝塞尔曲线  
- 不在本版强制完成异形实体的完整「拉边改顶点」CAD（见 §9 开放项）  
- 不做视频

## 3. 术语

| 术语 | 含义 |
|---|---|
| **异形实体（Solid / MeshSolid）** | 实体化产物：用户感知为 **一块** 障碍；权威几何为闭合多边形 + 三角网格 |
| **三角拼接** | 对简单多边形做三角剖分；网格三角形共边拼接，共同表示同一实体 |
| **矩形 block** | v1.3/v1.4 既有 `type=block` 轴对齐/旋转矩形；**不是**本版实体化目标产物 |
| **无边框（Borderless）** | 填充绘制时 **不画描边 pen**（或 pen 透明）；选中态可用极淡轮廓/手柄，避免「一圈线」感 |
| **绘图图形** | 草图折线、已提交线框的预览填充/折线（实体化前） |

## 4. 功能需求

### 4.1 实体化算法（核心）

| 编号 | 需求 | 优先级 |
|---|---|---|
| MS-01 | `wire.solidify` 成功时向 SceneWorld 添加 **1** 个异形实体，**禁止**再生成 N 个矩形 block 作为实体化结果 | P0 |
| MS-02 | 算法：闭合简单多边形 →（可选近点合并）→ **耳切或等价三角剖分** → 得到三角形列表，归属同一实体 id | P0 |
| MS-03 | **禁止**对三角形做 OBB/AABB 矩形拟合后当作碰撞体或主视觉 | P0 |
| MS-04 | 绘制：按三角形（或整多边形）**填充**异形区域；颜色建议与线框预览同色系，便于「画完即变成实体」的连续感 | P0 |
| MS-05 | 碰撞：球（圆）与 **三角形网格**（或与原多边形）做相交/推离；法线取命中边；行为稳定不穿模 | P0 |
| MS-06 | 自交、点数&lt;3、面积过小 → 实体化失败，不产生半截实体（继承 v1.5） | P0 |
| MS-07 | 实体化成功后仍删除草图与源线框（含表行），异形实体留下（继承 V5Q6） | P0 |
| MS-08 | 用户从外观与对象列表应能识别「这是一块异形」，而不是多个 obj | P0 |

**推荐管线（规范，非强制实现细节）：**

```
Wireframe(closed)
    → merge short edges
    → validate !selfIntersect && area≥min
    → triangulate → List<Triangle>
    → create ONE MeshSolid { id, polygon[], triangles[] }
    → remove wire + sketch
```

### 4.2 与既有 block 的关系

| 编号 | 需求 | 优先级 |
|---|---|---|
| BR-01 | 手动 `scene.add type=block` / 方块工具 **继续** 生成矩形 block | P0 |
| BR-02 | 异形实体使用 **新类型**（建议名：`solid` / `mesh` / `poly`，实现时定一名并贯彻指令/快照/投影） | P0 |
| BR-03 | 物理步进：既有 block OBB 碰撞 **保留**；新增圆–三角网格碰撞分支 | P0 |
| BR-04 | `scene_objects`（或新表）须能列出异形实体；顶点过多时表可只存摘要（id/type/tri_count），细顶点以快照+画布为准 | P1 |

### 4.3 无边框融合显示

| 编号 | 需求 | 优先级 |
|---|---|---|
| VI-01 | **草图**：折线与顶点默认弱化描边；推荐半透明折线、无粗黑边；近合提示可用虚线圈但不做成「实体边框」 | P0 |
| VI-02 | **已提交线框**：闭合预览用 **无描边半透明填充**（可保留极细顶点点）；不要粗描边框 | P0 |
| VI-03 | **异形实体**：常态 **无描边实心/半实心填充**；与线框预览同色相，实体化前后视觉连续 | P0 |
| VI-04 | **选中态**：允许淡色轮廓或顶点手柄（编辑需要），但非选中时必须无边框 | P0 |
| VI-05 | 手动矩形 block：建议同样改为 **非选中无描边**，仅选中显示手柄/淡轮廓，以便与异形实体并置时融合（若实现成本高，可 P1；**异形+线框绘图为 P0**） | P1 |
| VI-06 | 仿真态：异形实体保持填充可见；勿因去边框导致与背景糊成一片（对比度足够） | P0 |

### 4.4 编辑手势（异形）

| 编号 | 需求 | 优先级 |
|---|---|---|
| ED-01 | P0：**移动**整块异形（拖主体 → `scene.move` 或 `solid.move`） | P0 |
| ED-02 | P0：**删除**（Delete / `scene.remove`） | P0 |
| ED-03 | P1：旋转整块（绕中心） | P1 |
| ED-04 | P1：拖顶点改形并重算三角网格 | P1 |
| ED-05 | **不做**对异形套用矩形拉边手柄（那会再次暗示「它是方块」） | P0 |

### 4.5 指令（增量/修正）

| 指令 | 说明 |
|---|---|
| `wire.solidify [id=]` | 行为改正：产出 **1** 个异形实体，不再产出多 block |
| `solid.list` / `scene.list` | 能区分 block 与 solid |
| 既有 `wire.*` | 绘制/闭合流程保持；仅显示与 solidify 产物变化 |

（具体域名实现时遵守单点 `域.动作`。）

## 5. 数据与快照

### 5.1 建议 format

- 可继续 **format 3**，在 `objects` 中增加异形类型字段；或  
- **format 4**：`solids: [{ id, points:[{x,y}], triangles?:[[i,j,k]] }]`  

实现代理任选其一，但须：

| 规则 | 说明 |
|---|---|
| 权威 | 多边形顶点为权威；三角形可存盘或加载时重算 |
| 兼容 | 读旧档：无 solids → 空；若存在 v1.5.0 错误产生的「一堆 block」无法自动还原为异形（不强制迁移） |
| 线框 | `wireframes` 语义不变；实体化后仍删除 |

### 5.2 运行时模型（规范）

```
SceneWorld
  ├── Objects      // block / arrow / spawner / despawner（矩形等）
  ├── Solids[]     // 异形实体：Id, Points[], Triangles[]
  ├── Wireframes[]
  ├── Sketch
  └── Balls
```

（也可把 Solid 放进 Objects 用 `Type=Solid`，但碰撞与绘制必须走网格路径，不能当矩形。）

## 6. 碰撞规范（异形）

| 编号 | 要求 |
|---|---|
| PH-01 | 对每个三角形做圆–三角形分离；取穿透最大或首次命中策略须稳定 |
| PH-02 | 圆心在多边形内部时，推向最近边（与现有块内推出语义一致） |
| PH-03 | 异形 **不** 用「外接矩形」代替碰撞（那会挡到轮廓外的球） |
| PH-04 | 性能：单实体三角形数量建议软上限（如 256），超限 solidify 警告或拒绝 |

## 10. 验收标准（v1.5.1）

1. 画封闭三角形/凹多边形 → 实体化后 **对象数量 +1（异形）**，不是 +N 个矩形。  
2. 异形填充轮廓与线框一致（目视重合）；**非选中无描边**。  
3. 草图/线框预览 **无粗边框**；与实体化后色块可融合理解。  
4. 小球不能穿过异形；不能在轮廓外被「多余矩形」挡住。  
5. 自交仍无法实体化。  
6. 实体化后线框/草图删除；表 `wireframes` 无残留行。  
7. 手动方块工具仍可用；与异形可共存。  
8. 无第三方物理库；未改冻结区（或已上报）。  
9. 版本号 **1.5.1**。
