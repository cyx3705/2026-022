# WBall · v2.10 需求规划 —— 弹药队列、细格领地与炮台环形仪表

> 文档性质：派生应用需求规划（**不含实现代码**）。

> 纪律：`docs/二次开发演进手册.md` —— 只改 App 自由区；无新依赖；确定性不破。

## 0. 一句话定义

**v2.10** 把经济与火力的对应关系推到底：**左侧每结算一颗数值 m 的球 = 右侧入队一发炮弹**，弹的**大小与占领能力都由 m 决定（一数值 = 一格）**，不再有"按个数连发"；领地格子减半更细腻；炮台改为**环形仪表**（外圈护盾亮环 + 内圈血量更亮环 + 圆心标数），删除挡视野的名字卡片；落球区出球器改为 **360° 抛球机**并提高大数值概率。

## 1. 功能需求

### 1.1 细格与弹格对应（P0）

| 编号 | 需求 |
|---|---|
| CG-01 | `cellSize` 默认 20 → **10**（960×900 → 96×90 = 8640 格）；仍可配 |
| CG-02 | 数值 1 的炮弹直径 = 格宽（最小弹=最小格）；弹半径随数值缓增（`cellSize/2 × m^0.25`，封顶 5 格宽） |

### 1.2 弹药队列（P0，发弹规则大改）

| 编号 | 需求 |
|---|---|
| AM-01 | 阵营新增**弹药队列**：左侧非护盾槽结算数值 m → 入队一发弹（记录 m 与槽武器名）；队列上限 512，满则丢弃 |
| AM-02 | 炮台按射速逐发出队发射：**一次一发**，不再按 ProjectileCount 连发；**队列空则不开火**（火力完全来自落球） |
| AM-03 | 弹的占领预算 = m（**一数值一格**）；速度/散布沿用该弹武器定义 |
| AM-04 | 开局每炮台预载 12 发数值 1 的弹（避免开场冷场）；护盾槽语义不变 |
| AM-05 | `mode=direct` 保留旧"火力参数连发"路径不变 |

### 1.3 炮台环形仪表（P0）

| 编号 | 需求 |
|---|---|
| TU-01 | **删除名字卡片**（挡视野）；名字仅保留在顶部 HUD 计分条 |
| TU-02 | 炮台半径 44 → **26**（默认 `turretRadius=26`） |
| TU-03 | **外圈亮环 = 护盾**（占比弧，阵营亮色）；**内圈更亮环 = 血量/领地占比**；环空段显示暗轨 |
| TU-04 | **圆心直接标数值**（当前领地格数，K/M 格式），随占地增减实时变化 |
| TU-05 | 光晕/旋转炮管/粒子喷流保留（粒子随炮台变小适度减量） |

### 1.4 落球区改动（P0）

| 编号 | 需求 |
|---|---|
| DR-01 | **360° 抛球机**：球回到出球器后以确定性随机角度（0~360°）与初速抛出，形成喷泉式布球；开局吐球同样 |
| DR-02 | **提高大数值概率**：两侧新增 **X32 高倍边门**（竖条），倍率行提升为 16/8/4/2…4/8/16；配合抛球机可链式过门 |
| DR-03 | 重力维持 4g（v2.9 减速不回退） |

## 2. 验收标准

1. 数值 1 弹 = 一格大小、啃一格即消；数值 64 弹明显更大、可连啃 64 格；弹药队列空时炮台停火。
2. 炮台无卡片遮挡；外环护盾、内环血量随战局变化，圆心数字 = 领地格数。
3. 出球器 360° 喷球，可见球被抛向两侧过 X32 门；结算数值上限明显高于 v2.9。
4. 60 秒无头验证：战局未终、领地变化、同种子哈希一致；构建零警告；版本 **2.10.0**。
