## 0. 一句话定义

**v1.4** 在已交付的落球区之上，补齐三类编辑能力：

1. **场景尺寸可配**：右侧可设场景宽高；**场景边界之外**以「正方体/方块式实体区」呈现（可视 + 参与碰撞）；
2. **多场景表管理**：用投影表管理已有场景文件（列表 / 加载 / 元数据），与现有 `scene.save/load` 衔接；
3. **方块鼠标精修**：对方块做拖拽移动、旋转、拉边改长宽。

**线框作画器 → 一键实体化**列为 **v1.5 可选**，本文件只写清接口预留与验收边界，**不纳入 v1.4 必交付**。

## 1. 背景与目标

### 1.1 为何需要 v1.4

v1.3 已具备：四类对象、仿真、投影表、场景 JSON 存取。缺口在于：

| 缺口 | 用户痛点 |
|---|---|
| 场景世界大小固定/随窗口漂 | 无法稳定设计关卡比例；球飞出「世界」语义不清 |
| 多场景仅靠文件名手输 | 场景一多难管理，缺少表视图 |
| 方块只能粗放放置 / 指令改参 | 缺少旋转与拉边等鼠标精修，编辑效率低 |

### 1.2 v1.4 目标

| 编号 | 目标 |
|---|---|
| G1 | **场景尺寸**：右侧面板（及等价指令）可设置场景逻辑宽高；画布按该尺寸绘制世界 |
| G2 | **界外实体区**：场景矩形之外显示为连续的方块式固体区域（视觉上类似「围成/填满的正方体墙体」）；小球与界外固体碰撞，不穿出场景 |
| G3 | **场景管理表**：投影表（或等价表）列出 scenes 目录中的场景；支持加载、刷新、显示基本元数据 |
| G4 | **方块手势**：选中方块后可用鼠标移动、旋转、调整长宽；全部经指令回显，权威仍在 SceneWorld |
| G5 | **不破坏 v1.3 不变量**：运行时权威、位置不入库、投影表改必进场景、无第三方物理库、无视频 |

### 1.3 非目标（v1.4）

- 不做视频录制 / 导出 / 预览窗。
- **不做线框作画器与一键实体化**（→ §10 v1.5）。
- 不引入第三方物理引擎。
- 不改 AppShell 指令语法 / Core 契约 / DockingHost（冻结区）。
- 不把「场景尺寸」做成仅缩放视图而不改世界逻辑边界（视图缩放已有；本版是**世界尺寸**）。

## 2. 与 v1.3 的关系

```
WBall v1.3.0
  · SceneWorld 权威 · scene.save/load · balls/scene_objects 投影
  · 方块/箭头/生成器/销毁器 · 自研物理
        │
        │  v1.4 增量（本文）
        ▼
WBall v1.4
  · 场景宽高 + 界外实体墙
  · scenes 管理表
  · 方块移动/旋转/拉边
        │
        │  v1.5 可选（本文仅规划）
        ▼
  · 线框作画器 → 封闭线框实体化
```

| v1.3 能力 | v1.4 如何复用 |
|---|---|
| `scene.save/load/files/verify` | 场景表的加载/刷新调用同一套；快照增加 `worldWidth/worldHeight` |
| `scene_objects` 投影 | 方块旋转/尺寸变更后刷投影；场景表为**新表**，不与对象表混用 |
| 右侧 `dropzone` 面板 | 增加场景宽、高数字框 + 应用按钮 |
| 方块 AABB 碰撞 | 界外实体区复用球-方块碰撞；旋转方块需扩展为 OBB 或「旋转后的等价碰撞」 |

## 3. 术语

| 术语 | 含义 |
|---|---|
| **场景尺寸（World Size）** | SceneWorld 逻辑宽高（像素），与视图缩放无关 |
| **场景内区** | `[0, WorldWidth) × [0, WorldHeight)` 的可编辑落球舞台 |
| **界外实体区（Out-of-Bounds Solids）** | 场景矩形之外、用于显示与碰撞的固体区域；视觉呈「方块/正方体墙体」拼合或连续固体带 |
| **场景表（scenes 投影表）** | 列出 `workspace/scenes/*.json` 的管理表，非运行时对象权威 |
| **方块手势** | 对 `type=block` 的鼠标移动 / 旋转 / 拉边改尺寸 |
| **线框（Wireframe）** | v1.5：由折线构成的闭合多边形路径 |
| **实体化（Solidify）** | v1.5：将封闭线框转为一个或多个 block 实体 |

## 4. 功能需求

优先级：**P0** v1.4 必须 ｜ **P1** v1.4 尽量 ｜ **P2** 可后置或划入 v1.5

### 4.1 场景尺寸设置

| 编号 | 需求 | 优先级 |
|---|---|---|
| WS-01 | SceneWorld 增加明确的 `WorldWidth` / `WorldHeight`（逻辑像素）；默认建议 800×600，可配置 | P0 |
| WS-02 | 右侧落球工具面板提供「场景宽」「场景高」数字框 +「应用尺寸」按钮；指令模板驱动 | P0 |
| WS-03 | 等价指令：`scene.size w= h=`（或 `scene.setsize`）；`scene.size` 无参时查询当前尺寸 | P0 |
| WS-04 | 应用新尺寸后：画布世界边界立即更新；`scene.save` 写入快照；投影/场景表元数据可反映（见 §4.3） | P0 |
| WS-05 | 尺寸约束：最小边长 ≥ 200；最大边长 ≤ 4000（可配置常量）；非法值拒绝并提示 | P0 |
| WS-06 | 缩小场景时：仍完全落在新边界内的对象保留；**部分或全部越界的对象**——默认 **保留坐标不自动删除**，但仿真时与界外墙交互；可选 P1「应用时裁剪/提示」 | P0（保留）/ P1（裁剪策略） |
| WS-07 | 视图缩放/平移不改变 WorldSize；HUD 显示当前 `宽×高` | P0 |

### 4.2 界外实体区（场景外「正方体实体」）

> 用户表述：「场景外直接变成类似正方体的实体区显示」。  
> 产品语义定为：**场景矩形之外视为固体世界**——既要看得见，又要挡小球。

| 编号 | 需求 | 优先级 |
|---|---|---|
| OB-01 | 场景内区背景保持可编辑网格/画布；**场景外**填充为实体外观（建议深灰/石质色块，可带轻微网格分块以呈「方块堆砌」感，勿做成透明虚空） | P0 |
| OB-02 | 碰撞：小球不得穿出场景内区；与四壁（及可选的「界外填充固体」）按固体响应——等价于场景四周存在静态方块墙，或对界外区域做固体查询 | P0 |
| OB-03 | 界外实体**不是** `scene_objects` 里用户可逐个选中删除的普通方块；属场景级隐式几何，不进对象表行（避免表爆炸） | P0 |
| OB-04 | 编辑态与仿真态均显示界外实体外观；编辑态可在内区放置对象，点击界外不放置（或提示「超出场景」） | P0 |
| OB-05 | 改变 WorldSize 时，界外区域随边界重算，无需用户重摆墙 | P0 |
| OB-06 | （可选）面板开关「显示界外实体纹理」——关闭时仍碰撞，仅简化绘制 | P1 |

**实现提示（规范非强制）**：用四块超厚 AABB 墙贴在场景四边外侧，或对「点在矩形外」做固体法向反弹；视觉上在画布于世界矩形外绘制实体填充。旋转方块仍只存在于内区。

### 4.3 场景管理表

> v1.3 已有多场景文件与 `scene.files`；v1.4 用**表**做管理壳。

| 编号 | 需求 | 优先级 |
|---|---|---|
| SM-01 | 新增投影/管理表 `scenes`（名称可微调），一行 = 一个场景文件 | P0 |
| SM-02 | 建议列：`name`（文件名）、`path`（相对 scenes/）、`width`、`height`、`object_count`、`ball_count`、`updated_at`；**不存**运行时球位置 | P0 |
| SM-03 | 表数据来源：扫描 `workspace/scenes/*.json` + 读取快照头字段；**不是**场景权威（权威仍是文件 + 当前 SceneWorld） | P0 |
| SM-04 | `scene.refresh`（或打开表时自动）：刷新 `scenes` 表行 | P0 |
| SM-05 | 加载：表内操作或指令 `scene.load file=`；建议表按钮/面板「加载选中」发指令 | P0 |
| SM-06 | 双击资源窗口场景文件仍可加载（v1.2.1 已有）；与表加载等价 | P0 |
| SM-07 | （P1）从表「另存为 / 删除文件」——删除须确认且进回收站或仅删文件；须走指令 | P1 |
| SM-08 | 当前已加载场景在表中可高亮或 `is_current` 列 | P1 |
| SM-09 | 禁止用 `db.update` 改 `scenes` 行来「改磁盘文件名」而不走专用指令——若允许改表，必须拦截并映射为 `scene.rename` 等；**推荐 v1.4：scenes 表只读 + 指令加载/刷新** | P0（只读推荐） |

### 4.4 方块的鼠标移动 / 旋转 / 长宽调整

| 编号 | 需求 | 优先级 |
|---|---|---|
| BK-01 | **移动**：选择工具下拖拽方块主体；松开时发 `scene.move`（或 `scene.set`）回显；拖中可仅改内存并在松手提交指令（与 v1.3 拖拽一致并扩展到手势结束） | P0 |
| BK-02 | **长宽**：选中方块后显示边/角控制点；拖边改 w 或 h，拖角可同时改；松手发 `scene.set id= w= h=`（及必要时 x/y 以保持锚点合理） | P0 |
| BK-03 | **旋转**：选中方块后提供旋转手柄（建议顶部外侧圆点）或 Alt+拖拽；松手写入 `rotation`（度，顺时针，0=轴对齐）；发 `scene.set id= rotation=` | P0 |
| BK-04 | SceneObject / 快照 / `scene_objects` 投影增加 `rotation` 字段（度，默认 0）；`scene.add` 可带 `rotation=` | P0 |
| BK-05 | 碰撞：`rotation≠0` 时方块按 **OBB（定向包围盒）** 与球碰撞，不允许穿模；性能目标与 v1.3 同量级 | P0 |
| BK-06 | 绘制：方块按 rotation 旋转绘制；选中框与手柄跟旋转对齐 | P0 |
| BK-07 | 非 block 类型（箭头/生成器/销毁器）：v1.4 **不要求**旋转手柄；移动保留；拉边改尺寸 P1 | P1 |
| BK-08 | 旋转吸附：默认 15° 吸附，可关（面板或按住 Shift 临时取消） | P1 |
| BK-09 | 一切手势最终经指令总线；禁止只改画布不改 SceneWorld | P0 |

### 4.5 指令增量（草案）

语法仍遵守模板 §5.1（**域.动作**，仅一个点）。

| 指令 | 说明 |
|---|---|
| `scene.size [w=] [h=]` | 查询或设置场景逻辑尺寸 |
| `scene.refresh` | 刷新 `scenes` 管理表 |
| `scene.set` | 扩展支持 `rotation=`；方块手势松手调用 |
| `scene.add` | 扩展支持 `rotation=` |
| 既有 `scene.save/load/...` | 快照读写 `worldWidth/worldHeight`（及对象 `rotation`） |

面板新增控件示例：

- 数字框 `worldW` / `worldH` + 按钮 `scene.size w={worldW} h={worldH}`
- 按钮 `scene.refresh`
- （可选）「加载表中场景」——若表选中难从面板取得，可仅用控制台 / 表窗口工具条（实现时定）

## 5. 数据与快照变更

### 5.1 SceneSnapshot（相对 v1.3）

新增字段（format 可升为 **2**，加载时兼容 format=1：缺省宽高用 800×600，缺省 rotation=0）：

```json
{
  "format": 2,
  "worldWidth": 800,
  "worldHeight": 600,
  "objects": [
    { "id": "obj1", "type": "block", "x": 0, "y": 0, "w": 40, "h": 40, "rotation": 30 }
  ]
}
```

| 规则 | 说明 |
|---|---|
| 权威 | 仍为 **文件 ↔ SceneWorld**；库不 hydrate |
| 界外实体 | **不**序列进 objects 列表 |
| 投影 | `scene_objects` 增加 `rotation`；`scenes` 为管理表 |

### 5.2 `scenes` 表示意

| 列 | 说明 |
|---|---|
| name | `demo.json` |
| width / height | 自快照读取 |
| object_count / ball_count | 自快照读取 |
| updated_at | 文件修改时间 |
| is_current | 是否等于 `LastScenePath`（P1） |

## 6. UI / 交互要点

### 6.1 落球区

- 清晰绘制**场景内区边界**（描边）；
- 界外实体填充与内区对比鲜明；
- 选中方块：边框 + 边/角控制点 + 旋转手柄；
- HUD 增加：`场景 800×600`。

### 6.2 右侧面板

在现有落球工具中增加「场景」分组：宽、高、应用尺寸、刷新场景表。

### 6.3 表窗口

- 用户可切换查看 `balls` / `scene_objects` / **`scenes`**；
- `scenes` 默认只读（推荐）；加载通过指令。

## 7. 交付阶段（v1.4）

```
E0 场景尺寸+界外实体 ──▶ E1 快照兼容+面板指令 ──▶ E2 场景管理表
                                                      │
              v1.4 完成 ◀── E4 总验收 ◀── E3 方块旋转/拉边手势 ◀──┘
```

| 阶段 | 内容 | 出口 |
|---|---|---|
| **E0** | WorldSize + 界外绘制与碰撞 | 改尺寸后面板/指令生效；球撞墙不穿出 |
| **E1** | 快照 format2、面板、`scene.size` | save/load 恢复宽高；旧档可加载 |
| **E2** | `scenes` 表 + refresh/load 联动 | 表能列出场景并加载 |
| **E3** | 方块移动/拉边/旋转 + OBB 碰撞 + 投影 rotation | 鼠标精修回显指令；斜放方块挡球 |
| **E4** | 回归 v1.3 能力 + §9 验收 | 版本号 **1.4.0** |

建议体量：约 **5～8 人日**（单人全职粗估）。

## 8. 验收标准（v1.4 可勾选）

1. 右侧设置场景为非默认尺寸（如 1000×700）并应用；画布内区边界与 HUD 一致。
2. 界外区域显示为实体块外观；小球在仿真中不能穿出内区。
3. `scene.size` 查询/设置可用；非法尺寸被拒绝。
4. `scene.save` 后重启或 `scene.load`，宽高与对象（含 rotation）恢复；format=1 旧场景可加载。
5. `scenes` 表列出 scenes 目录文件；`scene.refresh` 后行数正确；能通过指令加载表中某场景。
6. 鼠标拖拽移动方块，控制台有等价指令；SceneWorld 与投影一致。
7. 拉边/拉角改变方块长宽，松手后尺寸正确且可挡球。
8. 旋转方块至非 0°，绘制正确；球与斜放方块碰撞不穿模。
9. 界外实体不出现在 `scene_objects` 表中作为可删行。
10. 无第三方物理库；无视频功能；未改 AppShell 冻结区（或已按手册上报获批）。

## 11. 风险

| 风险 | 应对 |
|---|---|
| 旋转方块碰撞变复杂 | 自研 OBB-圆；单测边角案例；不引入物理库 |
| 界外填充绘制过大 | 只绘制可视裁剪区；碰撞用解析边界 |
| 场景表与文件不同步 | `scene.refresh`；load/save 后自动刷新 |
| 指令名多段点 | 遵守解析器单点规则（如 `ball.addprop` 先例） |
| 与投影表双向同步 | 沿用 v1.3：改 SceneWorld → 刷投影；表改拦截进 SceneWorld |
